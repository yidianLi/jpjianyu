基础信息

API 基础URL

http://10.8.0.12:8080/api/v1  （网关 http://127.0.0.1:8081/ai）

认证方式

所有接口 HTTP 头携带认证信息：

Authorization: Bearer YOUR_TOKEN
X-Device-Id: PDA-03            # app 端必填，绑定 equipment 白名单
X-Timestamp: 1758355200000     # 毫秒戳，±5分钟外拒绝，防重放
X-Sign: HMAC(token+timestamp+body)  # app 写接口必填，防篡改
Idempotency-Key: RK100001:1:RK # 过账/提交必填 = idem_key，重复直接返原结果

请求格式

  • Content-Type：application/json
  • 字符编码：UTF-8
  • 请求方法：GET、POST、PUT、PATCH、DELETE（RESTful：GET查 / POST新增过账 / PUT全量改 / PATCH局部改 / DELETE逻辑删优先）
  • 分页：page/page_size，默认1/20，最大200

响应格式

所有 API 统一 JSON：

{"code":200,"msg":"成功","data":{},"total":0}

code：200成功 / 400参数错 / 401未鉴权 / 403无权限或护栏拦截 / 404不存在 / 409幂等重放返原结果 / 429限流 / 500异常。data 无数据返 {} / [] 禁 null；列表必返 total。数量 DECIMAL(18,3)、金额 DECIMAL(18,2)。

安全总则（每个接口通用，未逐条重复）

鉴权：Bearer 必校验，过期/伪造 401；AI 只读账号调写接口 403 AI_WRITE_DENIED。授权：按 sys_role/sys_perm + data_scope（仓库/车间/客户）过滤，越权 403 SCOPE_DENIED。防重放：X-Timestamp ±5min + X-Sign。幂等：写接口 Idempotency-Key，409 返原结果不重复记账。校验：unit 必须等于档案 base_unit；LY 实发≤可用；JS/PD/SQ 不动账由后端强制。脱敏：phone 中间4位*、sn 只返后4位。限流：单账号 60QPS/日10万，AI 问答 10QPS，429 带 Retry-After。审计：过账/审批/签收全写 audit_log(o_val/n_val+device)。
