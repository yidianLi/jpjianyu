0. 通用规范＋业务总览（腾讯规范落地）

0.1 业务定位（一句话）

物料管理成品管理仓储作业=进出库地点
域管什么不管什么菜单
物料管理物料档案＋DJ/JS/RK/LY/TK全生命周期，BOM的消耗侧不管库位本身，不管成品交付物料明细/申请领料/物料登记/来料拒收/物料入库/物料领用/车间退料/物料退库
成品管理成品档案＋CP/RK-FIN/TC/JJ＋生产工单WO，BOM的产出侧不管物料采购价，不管库位建设成品明细/成品登记/成品入库/成品退仓/成品交付
仓储作业物料和成品的进出库地点：仓库/库区＋现存＋流水＋调仓＋盘点不管配方、不管单价、不管审批流定义仓库库存/库存记录/库区管理/库存调仓/库存盘点
BOM是桥：bom_master（一成品多版本，启用仅一）→ bom_line（成品⇒物料＋qty＋loss_rate）。领料按BOM展开，完工按BOM倒冲，快照存 doc_line.bom_version。仓储只校验 wh/loc 是否存在、stock_kind MAT/FIN/ALL 是否允许存放。

0.2 RESTful＋版本＋路径

方式用途示例
GET查询（明细/库存/流水/树），无请求体可缓存GET /api/v1/web/stock/onhand
POST新增、建单、过账、确认、展开、完工POST /api/v1/web/docs、POST /api/v1/web/wo_tasks/{wo_no}/issue
PUT全量更新档案PUT /api/v1/web/masters/materials/{code}
PATCH局部更新（启用/收货/复核/发布）PATCH /api/v1/web/transfer_ships/{doc_no}/receive
DELETE逻辑删优先，物理删仅关联表DELETE /api/v1/web/system/user_roles
路径全小写下划线名词，禁止驼峰。版本进URL：/api/v1/web（PC）、/api/v1/app（PDA）、/api/v1/ai（问答/OCR）。新增只加路由不改旧字段；加业务在 sys_biz_state/sys_bill_method 加行，禁加列。

0.3 公共头＋分页＋统一返回

位置字段必填说明
HeaderAuthorization: Bearer token是AI只读账号同样携带，后端按角色禁写
HeaderX-Device-Idapp必填如PDA-03，绑定equipment白名单
HeaderX-Timestamp是毫秒戳，±5分钟外拒绝，防重放
HeaderX-Signapp写必填HMAC防篡改
HeaderIdempotency-Key过账/提交必填doc_no:line_no:biz，重复409返原结果
Querypage/page_size列表必填默认1/20，最大200
{"code":200,"msg":"成功","data":{},"total":0}
成功有数据、失败有说明、空值有兜底：data无数据返{}/[]禁null；列表必返total；数量DECIMAL(18,3)金额DECIMAL(18,2)；单据unit必须等于档案base_unit，防米+件混加。错误码：OVER_ISSUE/DUP_SCAN/SCOPE_DENIED/CHECKLIST_EMPTY/DIFF_REASON_REQUIRED/BOM_VERSION_REQUIRED/DOC_NOT_FOUND/MATERIAL_NOT_FOUND/PRODUCT_NOT_FOUND/FLOW_STATE_DENIED/AI_WRITE_DENIED/IDEMPOTENT_REPLAY/RATE_LIMITED。

1. 仓储作业（5个二级菜单：只管进出地点）

GET仓库库存（现存量总览）

GET /api/v1/web/stock/onhand?wh=&loc=&material_code=&product_code=&page= — stock_onhand快照（PK含material+product；物料行product为空串反之亦然；问答默认查此表）
参数说明
wh/loc仓库/库位，只许选warehouse/location存在且stock_kind允许
material_code/product_code二选一过滤，物料账/成品账
{"code":200,"msg":"成功","data":[{"material_code":"HD-OXF-001","wh":"WH-A","loc":"WH-A-01","on_hand":1200.000,"avail":1000.000}],"total":1}

GET库存记录（出入库流水）

GET /api/v1/web/stock/ledger?doc_no=&barcode=&batch_no=&biz=&product_code=&page= — stock_ledger只增不改；差异仲裁以此为准只报警不锁

GET库区管理（仓库＋库位档案）

GET /api/v1/web/masters/warehouses — warehouse（WH-A外仓/WH-B内仓1/WH-C内仓2；wh_type原料仓/成品仓/待检区/隔离区；stock_kind MAT/FIN/ALL）
POST /api/v1/web/masters/warehouses — 新建仓库
GET /api/v1/web/masters/locations?wh_code=WH-A — location（loc_code结构化主键＋qr_code＋capacity）
POST /api/v1/web/masters/locations — 新建库位；PATCH /locations/{loc_code}/enabled — 停用（有库存只能停用不能删）

GET库存调仓（DB单＋在途）

GET /api/v1/web/transfer_ships?to_wh=&diff_status=&page= — transfer_ship（o_qty申请/已发/n_qty实收＋carrier/plate/eta只读＋diff_status）
POST /api/v1/web/transfer_ships — 新建调仓（from_wh/to_wh/unit必填，sid=19000）
PATCH /api/v1/web/transfer_ships/{doc_no}/receive — 收货确认（n_qty实收，差异进diff_status）

GET库存盘点（PD单）

GET /api/v1/web/pd_tasks?wh_code=&biz_status=&page= — pd_task（02:30自动/人工临时，范围冻结，sid=13100，pd_no=PD[SERIAL:6]）
POST /api/v1/web/pd_tasks — 新建盘点
GET /api/v1/web/pd_tasks/{pd_no}/lines — pd_line（o_qty账面/n_qty实盘/diff_qty=N-O＋reason）
POST /api/v1/web/pd_tasks/{pd_no}/confirm — 复核（PD不动账，确认后另生TK/RK调账）

GET仓储溯源（库存记录下钻）

GET /api/v1/web/stock/trace?code= — SB/BT/单号同一框（timeline＋suspect前后3笔＋缺关联标红）

2. 物料管理（8个二级菜单：物料主线）

GET物料明细（档案＋现存＋批次）

GET /api/v1/web/masters/materials?keyword=&cat_code=&enabled=1&page= — mat_master（仅物料；base/pack/sub三计量；manage_mode QTY/CODE；max/min预警）
GET /api/v1/web/masters/materials/{material_code} — 详情（含批次余量聚合）
GET /api/v1/web/masters/mat_categories — mat_category分类树（面料/辅料/五金/包装/耗材，autocode排序）
GET /api/v1/web/stock/batches?material_code= — batch（BT级溯源）；GET /api/v1/web/stock/items?batch_no= — material_item（SB级）

POST申请领料（申请单，不扣账）

POST /api/v1/web/docs — {"type":"SQ","sid":11600} 申请（只登记需求，不动onhand/avail，不写ledger）
GET /api/v1/web/docs?type=SQ&biz_status=&page= — 申请列表；POST /docs/{doc_no}/approve — 审批通过后转LY领用（按BOM/库存校验可用量）
申请≠领用：申请只留痕，领用才过账扣账。LY超发拦OVER_ISSUE。

POST物料登记（DJ建档＋初始0）

POST /api/v1/web/docs — {"type":"DJ","sid":10000} 登记（物料建档，初始库存必须0，期初走RK单；CODE模式生成条码，QTY模式生成批次）

POST来料拒收（JS凭证不动账）

POST /api/v1/web/docs — {"type":"JS","sid":10200} 拒收（只更新来源单qty_reject与状态，不写ledger、不改onhand；01整批/02部分/99其他）

POST物料入库（RK验收上架）

POST /api/v1/web/docs — {"type":"RK","sid":10100} 入库（lines填material_code＋qty＋unit=base_unit＋loc；单号RK[SERIAL:6]）
curl -X POST http://10.8.0.12:8080/api/v1/web/docs -H "Content-Type: application/json" -H "Authorization: Bearer xxx" -H "Idempotency-Key: RK100001:1:RK" -d '{"type":"RK","sid":10100,"bmid":1,"handler":"李小明","lines":[{"material_code":"HD-OXF-001","qty":1200,"unit":"米","loc":"WH-A-01"}]}'
POST /api/v1/web/docs/{doc_no}/post — 过账（改onhand/avail＋写ledger＋audit_log；幂等409返原结果）

POST物料领用（LY扣账＋可按BOM展开）

POST /api/v1/web/docs — {"type":"LY","sid":10400} 领用（记录领用人/车间/班组/工位；实发≤可用，否则OVER_ISSUE）
POST /api/v1/web/wo_tasks/{wo_no}/issue — 生产领料快捷：按bom_version自动展开LY行（qty×qty_plan×(1+loss_rate)）

POST车间退料（余料回仓，回增可用）

POST /api/v1/web/docs — {"type":"TK","sid":15000,"bmid":余料回仓} 车间余料回仓（avail回增，material_item回在库并写回库位；须关联原LY单）

POST物料退库（冲红/退供，不改历史）

POST /api/v1/web/docs — {"type":"TK","sid":15000} 入库冲红（反向流水，原单转REVERSED，历史不改）／损坏退还供应商（avail扣减，可关联JS单）
GET /api/v1/web/docs/{doc_no} — 详情含o_qty/n_qty/o_loc/n_loc快照＋附件＋审批流
POST /api/v1/web/docs/{doc_no}/submit · /post · /approve — 提交/过账/审批（S1..S6按flow_def）

POST成品登记（CP建档）

GET生产工单（成品线引擎）

GET /api/v1/web/wo_tasks?product_code=&biz_status=&page= — wo_task（product_code＋bom_version＋qty_plan/qty_done，workshop取org叶子）
POST /api/v1/web/wo_tasks — 下单（bom_version必填，否则BOM_VERSION_REQUIRED；wo_no=WO[SERIAL:6]）
