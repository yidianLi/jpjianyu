## 2. 可执行 DDL（MySQL 5.6，唯一真源引用版）

真源 `backend/sql/wms.sql` v2.3，可直接执行，不再本文复述建表全文：

- 库 `wms`，`InnoDB`，`utf8mb4`，目标 `MySQL 5.6`；文件头含 `CREATE DATABASE + USE`，空库一次跑通，重跑仍成功（`CREATE TABLE IF NOT EXISTS`＋种子幂等`INSERT..ON DUPLICATE KEY`，无独立`CREATE INDEX`）。
- 63表＝0组编号中枢4表（`sys_config`容量声明／`sys_sequence`中央发号／`sys_biz_state`语义`sid` 15个／`sys_bill_method`方法`01/02/99`）＋业务59表（物料线/成品线BOM/仓储地点/工单单据/支撑）。
- 单号＝前缀＋`[SERIAL:6]`（如`RK100001`）；单据前缀：DJ登记/JS拒收/RK入库/LY领用/TK退库（01=车间退料TL回增/02=冲红/03=退供）/TC成品退仓/DB调仓/TZ调整/PD盘点/CP成品登记/RK成品入库（sid=11300）/JJ交付/WO工单/SQ申请领料（只申请不扣账）。
- 快照`o_/n_`（如`doc_line.o_qty/n_qty`、`pd_line.diff_qty=N-O`）；树表`autocode+lowest+parent_code`；状态`enabled/biz_status/flow_status/status`四位分离；无物理外键，关联字段全建索引。
- 表字段解释见 `docs/数据字典-V2.3.md`（与`wms.sql`同源生成），菜单口径见 `docs/菜单总览-V2.3.md`。

约束：`stock_ledger.idem_key = doc_no:line_no:biz`，重复提交唯一冲突直接返回原结果；`PD` 只记差异不改账，差异走 `TK/RK` 调整。
问答口径：默认查快照 `stock_onhand`，差异仲裁查 `stock_ledger` 汇总；两者不平时以流水为准，只报警不锁，不拦过账。
缺关联口径：缺码/缺批/缺关联不拦单，单照过；三处显性标出待处理（工单行标红缺项 → 点进 docs 补关联；时间线断点标`缺XX`＋嫌疑置顶；驾驶舱异常卡汇总待补数直达处理）。原型只验标出＋可补，真校验后置 P7。

## 3. 各模块实现要点与接口约定

### 3.1 PC 溯源 `pages/docs.html`（主入口，不新建页）

- 要点：同一框查 `SB/BT/单号`，`openTrace(code)` 出链＋嫌疑置顶（最后变动＋前后3笔），支持 `docs.html?code=` 直达；`stocktake.html` 差异行 `查去向` 带参跳。
- 接口：`GET /api/v1/web/trace?code=` → `{timeline:[{at,doc,biz,qty,unit,by,device,photo}], suspect:{last,around:[doc×3]}}`，无后端时走 `FieldDB` 本地链。

### 3.2 PDA `scan/data/home/register`

- `pda-scan.js`：`PdaScan.bind(input,fn)` 订阅；键盘楔走回车，广播走 `window.PdaScanFeed(code)`。厂家文档到后只改此文件 Intent 名。
- `scan.html`：查 `FieldDB.barcodes`，重复/无效拦截＋振动，成功行 `查看溯源 → data.html?code=`。
- `data.html`：`traceCard` 按条码出批次库位最后变动，按批次出聚合（整批少查 RK/发料，单件少查 LY/TL）。
- `register.html?biz=`：一页四态，`LY` 超发拦截（`qty≤avail`），`TL` 校验 `src_doc`，四态共用清单/扫码/批次组件。
- 接口：`POST /api/v1/app/scan {code,orderId}` → `{result:OK|DUPLICATE|INVALID, material,qty,unit}`；`POST /api/v1/app/submit {orderId,codes[],qty,unit,photos[]}`（无 sign，离线进 `mobile_sync_queue`）。

### 3.3 驾驶舱 `pages/dashboard.html`（PC 大屏，复用三域，无人均）

- 要点：卡片 `待办/库存/差异/周转 + 产能（无设备、无人均）`，异常卡直达 `docs.html?code=` 与 `stocktake.html?pd=`；手动/按班刷新按钮，不做秒级推送；PDA 不做；只做 PC 驾驶舱。
- 反推公式（界面现有数据，答案须附公式原文）：
  - 发料量 `Σledger WHERE biz='LY'`
  - 成品入库 `Σledger WHERE biz='RK' AND product_code LIKE 'CP-%'`（V2.3起成品独立`product_code`，不再用`material_code LIKE 'CP-%'`）
  - 退料率 `Σ(TK) / Σ(LY)`（车间退料TL即TK-01回仓进项，退库TK即02/03减项；按 qty 同单位分组，单位不同分开展示）
- 接口：`GET /api/v1/web/dashboard` → `{kpi:{todo,onhand,diff,turnover,capacity}, alerts:[{doc,reason,link}]}`，全部由三域聚合，不新增聚合表。

### 3.4 AI 网关 `/api/v1/ai/*`（禁过账强制）

- `POST /ai/text2sql {question}` → 网关拼 scope＋三域 schema → Qwen 生成 SQL → `guards.py` 白名单校验（只许单条 `SELECT`，表仅 `doc_main/doc_line/stock_onhand/stock_ledger/material_item/batch`，禁 `INSERT/UPDATE/DELETE/post/过账/确认`，`LIMIT ≤200`，答案不含照片/OCR候选只给数和单号）→ 只读账号执行 → `{rows, sql, formula}` 并写 `ai_qa_log`。反推数答案必须附公式原文。
- `POST /ai/ocr {image}` → Paddle → `{candidates:{customer,qty_ocr,conf}, ocrId}` 存 `ocr_document＋ocr_field_result`，页面低置信标红，人工覆盖才入单。
- `POST /ai/ask` 为问答编排（text2sql＋话术），同样只读。
- 适配器：`adapters/qwen.py` 内 `BASE_URL/KEY/MODEL` 三行切换百炼↔vLLM；`adapters/paddle.py` 内切换线上↔本地。

## 5. 分阶段开发计划与验收标准

- P0 基线冻结：归档双轨残留，`home` 二期置灰；`wms.sql` 空库一次跑通＋重跑一次仍成功（无独立`CREATE INDEX`报错）。验收：无死链 `transfer.html`，`git log` 可回放。
- P1 溯源闭环：`docs.html?code=`＋`stocktake查去向`＋PDA `scan→data` 直达。验收：`SB/BT/单号/LY/TL/PD` 各抽 2 个＋1 个盘点差异 `PD` 直查共 7 处，PC/PDA 同码同链，嫌疑可点，缺关联标出＋可补（不拦单）。
- P2 驾驶舱：`dashboard.html` 三域卡片＋双直达（`docs.html?code=` 与 `stocktake.html?pd=`，仅 PC）。验收：异常卡 1 次点击到单，手动刷新一致。
- P3 AI 网关 Mock：`ai/*` 契约＋白名单＋`ai_qa_log`。验收：无 key 可演示；写操作 SQL 一律被拒。
- P4 问答框：`docs.html#aiAsk` 三域问答。验收：库存/单据/流水各 3 问出数，原文 SQL 可审。
- P5 OCR 候选：`receipt.html#ocrBox`。验收：低置信须人工改才能存，候选进 `ocr_*` 表。
- P6 线上真调（百炼＋线上 OCR）：验收：真实数据问答可用，费用/日志可查；页面零改。
- P7 切内网 vLLM＋本地 Paddle：只改 `ai-gateway.yaml`。验收：断外网可用，同一问题结果一致，关闭外访。
