## 2. 可执行 DDL（PostgreSQL，可直接跑）

```sql
-- 主档/批次/单件：建码即绑来源
CREATE TABLE IF NOT EXISTS mat_master(
  material_code TEXT PRIMARY KEY, name TEXT NOT NULL, spec TEXT,
  unit TEXT NOT NULL, pack_qty NUMERIC NOT NULL DEFAULT 1,
  manage_mode TEXT NOT NULL DEFAULT 'QTY', status TEXT NOT NULL DEFAULT '启用'
);
CREATE TABLE IF NOT EXISTS batch(
  batch_no TEXT PRIMARY KEY, material_code TEXT NOT NULL REFERENCES mat_master(material_code),
  partner_id TEXT, source_doc_no TEXT, created_at TIMESTAMPTZ DEFAULT now(), created_by TEXT
);
CREATE TABLE IF NOT EXISTS material_item(
  barcode TEXT PRIMARY KEY, material_code TEXT NOT NULL REFERENCES mat_master(material_code),
  batch_no TEXT NOT NULL REFERENCES batch(batch_no),
  source_doc_no TEXT, status TEXT NOT NULL DEFAULT '在库'
);
-- 现存/流水：流水只增不改，过账唯一入口写
CREATE TABLE IF NOT EXISTS stock_onhand(
  material_code TEXT NOT NULL, batch_no TEXT NOT NULL, wh TEXT NOT NULL, loc TEXT NOT NULL,
  on_hand NUMERIC NOT NULL DEFAULT 0, avail NUMERIC NOT NULL DEFAULT 0,
  pending NUMERIC NOT NULL DEFAULT 0, quarantine NUMERIC NOT NULL DEFAULT 0, frozen NUMERIC NOT NULL DEFAULT 0,
  PRIMARY KEY(material_code,batch_no,wh,loc)
);
CREATE TABLE IF NOT EXISTS stock_ledger(
  id BIGSERIAL PRIMARY KEY, doc_no TEXT NOT NULL, line_no INT NOT NULL DEFAULT 1,
  material_code TEXT NOT NULL, batch_no TEXT, barcode TEXT,
  wh TEXT, loc TEXT, qty NUMERIC NOT NULL, unit TEXT NOT NULL,
  dir CHAR(1) NOT NULL CHECK(dir IN ('+','-')), biz TEXT NOT NULL,
  by_user TEXT NOT NULL, device TEXT, at TIMESTAMPTZ DEFAULT now(),
  idem_key TEXT UNIQUE NOT NULL
);
-- 关联/单据/附件/扫码/OCR/审计/AI问答日志
CREATE TABLE IF NOT EXISTS stock_doc_ref(
  id SERIAL PRIMARY KEY, from_doc TEXT NOT NULL, to_doc TEXT NOT NULL, rel TEXT NOT NULL,
  UNIQUE(from_doc,to_doc,rel)
);
CREATE TABLE IF NOT EXISTS doc_main(
  doc_no TEXT PRIMARY KEY, type TEXT NOT NULL CHECK(type IN ('DJ','RK','LY','TL','PD')),
  status TEXT NOT NULL DEFAULT 'DRAFT', handler TEXT, at TIMESTAMPTZ DEFAULT now()
);
CREATE TABLE IF NOT EXISTS doc_line(
  doc_no TEXT NOT NULL REFERENCES doc_main(doc_no), line_no INT NOT NULL,
  material_code TEXT NOT NULL, batch_no TEXT, qty NUMERIC NOT NULL, unit TEXT NOT NULL,
  PRIMARY KEY(doc_no,line_no)
);
CREATE TABLE IF NOT EXISTS doc_attachment(
  id SERIAL PRIMARY KEY, doc_no TEXT NOT NULL, kind TEXT NOT NULL,
  ref TEXT NOT NULL, by_user TEXT, at TIMESTAMPTZ DEFAULT now()
);
CREATE TABLE IF NOT EXISTS scan_log(
  id BIGSERIAL PRIMARY KEY, code TEXT NOT NULL, result TEXT NOT NULL,
  doc_no TEXT, by_user TEXT, device TEXT, at TIMESTAMPTZ DEFAULT now()
);
CREATE TABLE IF NOT EXISTS ocr_document(
  ocr_id TEXT PRIMARY KEY, doc_no TEXT, conf NUMERIC, ref TEXT, at TIMESTAMPTZ DEFAULT now()
);
CREATE TABLE IF NOT EXISTS ocr_field_result(
  ocr_id TEXT NOT NULL REFERENCES ocr_document(ocr_id), field TEXT NOT NULL,
  candidate TEXT, conf NUMERIC, PRIMARY KEY(ocr_id,field)
);
CREATE TABLE IF NOT EXISTS audit_log(
  id BIGSERIAL PRIMARY KEY, at TIMESTAMPTZ DEFAULT now(),
  by_user TEXT NOT NULL, action TEXT NOT NULL, doc_no TEXT, detail TEXT
);
CREATE TABLE IF NOT EXISTS ai_qa_log(
  id BIGSERIAL PRIMARY KEY, at TIMESTAMPTZ DEFAULT now(),
  by_user TEXT, question TEXT NOT NULL, sql TEXT NOT NULL, rows INT, ms INT
);
-- 溯源三索引（后端必建）
CREATE INDEX IF NOT EXISTS ix_ledger_barcode ON stock_ledger(barcode);
CREATE INDEX IF NOT EXISTS ix_ledger_batch ON stock_ledger(batch_no);
CREATE INDEX IF NOT EXISTS ix_ledger_doc ON stock_ledger(doc_no);
CREATE INDEX IF NOT EXISTS ix_item_batch ON material_item(batch_no);
```

约束：`stock_ledger.idem_key = doc_no:line_no:biz`，重复提交唯一冲突直接返回原结果；`PD` 只记差异不改账，差异走 `TK/RK` 调整。

## 3. 各模块实现要点与接口约定

### 3.1 PC 溯源 `pages/docs.html`（主入口，不新建页）

- 要点：同一框查 `SB/BT/单号`，`openTrace(code)` 出链＋嫌疑置顶（最后变动＋前后3笔），支持 `docs.html?code=` 直达；`stocktake.html` 差异行 `查去向` 带参跳。
- 接口：`GET /api/v1/web/trace?code=` → `{timeline:[{at,doc,biz,qty,unit,by,device,photo}], suspect:{last,around:[doc×3]}}`，无后端时走 `FieldDB` 本地链。

### 3.2 PDA `scan/data/home/register`

- `pda-scan.js`：`PdaScan.bind(input,fn)` 订阅；键盘楔走回车，广播走 `window.PdaScanFeed(code)`。厂家文档到后只改此文件 Intent 名。
- `scan.html`：查 `FieldDB.barcodes`，重复/无效拦截＋振动，成功行 `查看溯源 → data.html?code=`。
- `data.html`：`traceCard` 按条码出批次库位最后变动，按批次出聚合（整批少查 RK/发料，单件少查 LY/TL）。
- `register.html?biz=`：一页四态，`LY` 超发拦截（`qty≤avail`），`TL` 校验 `src_doc`，四态共用清单/扫码/批次组件。
- 接口：`POST /api/v1/app/scan {code,orderId}` → `{result:OK|DUPLICATE|INVALID, material,qty,unit}`；`POST /api/v1/app/submit {orderId,codes[],qty,unit,photos[]}`（无 sign，离线进 `mobile_sync_queue`）。

### 3.3 驾驶舱 `pages/dashboard.html`（PC 新增大屏，复用三域）

- 要点：卡片 `待办/库存/差异/周转 + 产能/人力`，异常卡点单直达 `docs.html`；手动/按班刷新按钮，不做秒级推送；PDA 不做。
- 接口：`GET /api/v1/web/dashboard` → `{kpi:{todo,onhand,diff,turnover,capacity,manpower}, alerts:[{doc,reason}]}`，全部由三域聚合，不新增聚合表。

### 3.4 AI 网关 `/api/v1/ai/*`（禁过账强制）

- `POST /ai/text2sql {question}` → 网关拼 scope＋三域 schema → Qwen 生成 SQL → `guards.py` 白名单校验（只许单条 `SELECT`，表仅 `doc_main/doc_line/stock_onhand/stock_ledger/material_item/batch`，禁 `INSERT/UPDATE/DELETE/post/过账/确认`，`LIMIT ≤200`）→ 只读账号执行 → `{rows, sql}` 并写 `ai_qa_log`。
- `POST /ai/ocr {image}` → Paddle → `{candidates:{customer,qty_ocr,conf}, ocrId}` 存 `ocr_document＋ocr_field_result`，页面低置信标红，人工覆盖才入单。
- `POST /ai/ask` 为问答编排（text2sql＋话术），同样只读。
- 适配器：`adapters/qwen.py` 内 `BASE_URL/KEY/MODEL` 三行切换百炼↔vLLM；`adapters/paddle.py` 内切换线上↔本地。

## 5. 分阶段开发计划与验收标准

- P0 基线冻结：归档双轨残留，`home` 二期置灰。验收：无死链 `transfer.html`，`git log` 可回放。
- P1 溯源闭环：`docs.html?code=`＋`stocktake查去向`＋PDA `scan→data` 直达。验收：抽 `SB/BT/单号` 各一，PC/PDA 同链，嫌疑可点。
- P2 驾驶舱：`dashboard.html` 三域卡片＋下钻。验收：异常卡 1 次点击到 `docs` 单，手动刷新一致。
- P3 AI 网关 Mock：`ai/*` 契约＋白名单＋`ai_qa_log`。验收：无 key 可演示；写操作 SQL 一律被拒。
- P4 问答框：`docs.html#aiAsk` 三域问答。验收：库存/单据/流水各 3 问出数，原文 SQL 可审。
- P5 OCR 候选：`receipt.html#ocrBox`。验收：低置信须人工改才能存，候选进 `ocr_*` 表。
- P6 线上真调（百炼＋线上 OCR）：验收：真实数据问答可用，费用/日志可查；页面零改。
- P7 切内网 vLLM＋本地 Paddle：只改 `ai-gateway.yaml`。验收：断外网可用，同一问题结果一致，关闭外访。
