二、接口详情 · 仓储作业

GET 仓库库存

安全：Bearer 鉴权必带；按 data_scope（仓库范围）过滤，越权 403 SCOPE_DENIED；只读不写账；快照 30 秒短缓存；phone/sn 等敏感字段脱敏，本口不返敏感字段。

请求

项说明
Method + PathGET /api/v1/web/stock/onhand
HeadersAuthorization: Bearer TOKEN、X-Timestamp（±5min 防重放）
Query 参数wh 仓库（可选，限 data_scope 内）；loc 库位（可选）；material_code 物料（可选）；product_code 成品（可选，与 material 二选一）；page 页码默认 1；page_size 每页默认 20 最大 200

请求示例

curl "http://10.8.0.12:8080/api/v1/web/stock/onhand?wh=WH-A&page=1&page_size=20" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "X-Timestamp: 1758355200000"

响应示例

{
  "code": 200,
  "msg": "成功",
  "data": [
    {"material_code":"HD-OXF-001","product_code":"","batch_no":"MB2026091003",
     "wh":"WH-A","loc":"WH-A-01","on_hand":1200.000,"avail":1000.000,
     "pending":0.000,"quarantine":0.000,"frozen":0.000,"unit":"米"}
  ],
  "total": 1
}

字段说明

字段含义
material_code物料编码，物料行为值，成品行为空串
product_code成品编码 CP-，成品行为值，物料行为空串
batch_no批次号 BT 级
wh / loc仓库编码 / 库位编码
on_hand账面现存数量 DECIMAL(18,3)
avail可用数量（领用上限）
pending / quarantine / frozen待发 / 隔离 / 冻结

错误码

400 参数错（分页越界）/ 401 未鉴权 / 403 SCOPE_DENIED（查非授权仓库）/ 429 限流 / 500 异常。

GET 库存记录

安全：Bearer 鉴权；data_scope 过滤；只增不改台账，禁止任何写操作；差异仲裁以本表为准，不平只报警不锁；只读。

请求

项说明
Method + PathGET /api/v1/web/stock/ledger
HeadersAuthorization: Bearer TOKEN、X-Timestamp
Query 参数doc_no 单号；barcode 条码 SB；batch_no 批次 BT；biz 业务前缀（LY/TK/…）；product_code 成品；page/page_size

请求示例

curl "http://10.8.0.12:8080/api/v1/web/stock/ledger?doc_no=LY100008&page=1&page_size=50" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "X-Timestamp: 1758355200000"

响应示例

{
  "code": 200,
  "msg": "成功",
  "data": [
    {"id":10000023,"doc_no":"LY100008","line_no":1,"sid":10400,
     "material_code":"HD-OXF-001","product_code":"","batch_no":"MB2026091003",
     "barcode":"SB2026091201","wh":"WH-A","loc":"WH-A-01","qty":200.000,
     "unit":"米","dir":"-","biz":"LY","by_user":"李小明","device":"PDA-03",
     "at":"2026-09-12 09:12:00","idem_key":"LY100008:1:LY"}
  ],
  "total": 1
}

字段说明

字段含义
id流水代理键 BIGINT 自增
doc_no / line_no来源单号 / 行号
sid语义动作码（10400=领用）
qty / unit变动数量 / 单位（数量必带单位）
dir方向：1 入 / -1 出
biz业务前缀，中文只做显示映射
idem_key幂等键 doc_no:line_no:biz 唯一

错误码

400 参数错 / 401 未鉴权 / 403 SCOPE_DENIED / 429 限流 / 500 异常。

POST 新建物料

安全：Bearer 鉴权 + 仅基础数据管理员角色（否则 403 SCOPE_DENIED）；base_unit 必填且后续单据 unit 必须等于它（防米+件混加）；新建物料初始库存必须 0，期初走 RK 单，禁带期初。

请求

项说明
Method + PathPOST /api/v1/web/masters/materials
HeadersAuthorization: Bearer TOKEN、Content-Type: application/json
Bodymaterial_code 唯一；name；base_unit；cat_code；spec；pack_unit/pack_qty；sub_unit/sub_qty；manage_mode QTY/CODE；price_ref；max_qty/min_qty；shelf_life_days

请求示例

curl -X POST "http://10.8.0.12:8080/api/v1/web/masters/materials" \
  -H "Authorization: Bearer YOUR_TOKEN" -H "Content-Type: application/json" \
  -d '{"material_code":"HD-OXF-002","name":"牛津布B","base_unit":"米",
       "cat_code":"MAT-FAB-01","pack_unit":"箱","pack_qty":50,
       "manage_mode":"QTY","max_qty":2000,"min_qty":100}'

响应示例

{"code":200,"msg":"成功","data":{"material_code":"HD-OXF-002","enabled":1},"total":1}

错误码

400 INVALID_QTY（缺 base_unit / 数量格式错）/ 401 未鉴权 / 403 SCOPE_DENIED（非管理员）/ 409 编码重复 / 429 限流 / 500 异常。

POST 建单（SQ 申请 / DJ 登记 / JS 拒收 / RK 入库 / LY 领用 / TK 退库）

安全：Bearer 鉴权 + Idempotency-Key 必填（= idem_key=doc_no:line_no:biz，重复 409 返原结果）；type 走 15 前缀白名单，非白名单 400；unit 必须等于档案 base_unit；SQ 申请 / JS 拒收只登记不动账，由后端强制不写 ledger；建单只落 DRAFT，过账另调 /post。

请求

项说明
Method + PathPOST /api/v1/web/docs
HeadersAuthorization: Bearer TOKEN、Content-Type: application/json、Idempotency-Key
Bodytype（SQ/DJ/JS/RK/LY/TK…）；sid（10000 DJ/10200 JS/10100 RK/10400 LY/15000 TK/11600 SQ）；bmid 方法；handler 经办人；lines[]：物料行 material_code、成品行 product_code + bom_version、qty、unit、loc、batch_no

请求示例

curl -X POST "http://10.8.0.12:8080/api/v1/web/docs" \
  -H "Authorization: Bearer YOUR_TOKEN" -H "Content-Type: application/json" \
  -H "Idempotency-Key: RK100001:1:RK" \
  -d '{"type":"RK","sid":10100,"bmid":1,"handler":"李小明",
       "lines":[{"material_code":"HD-OXF-001","qty":1200,"unit":"米","loc":"WH-A-01"}]}'

响应示例

{"code":200,"msg":"成功","data":{"doc_no":"RK100001","type":"RK","biz_status":"DRAFT"},"total":1}

错误码

400 参数错 / type 非白名单 / unit≠base_unit / 401 未鉴权 / 403 SCOPE_DENIED / 409 IDEMPOTENT_REPLAY（重复建单返原单）/ 429 限流 / 500 异常。

POST 提交

安全：Bearer 鉴权；状态机 DRAFT→待审批；写 flow_instance S1；不可提交已过账单，违者 403 FLOW_STATE_DENIED；审计留痕。

请求

项说明
Method + PathPOST /api/v1/web/docs/{doc_no}/submit
HeadersAuthorization: Bearer TOKEN
Path / Bodydoc_no 单号；Body 可空

请求示例

curl -X POST "http://10.8.0.12:8080/api/v1/web/docs/RK100001/submit" \
  -H "Authorization: Bearer YOUR_TOKEN"

响应示例

{"code":200,"msg":"成功","data":{"doc_no":"RK100001","biz_status":"APPROVING","cur_step":"S1"},"total":1}

错误码

401 未鉴权 / 403 FLOW_STATE_DENIED（状态不允许）/ 404 DOC_NOT_FOUND / 429 限流 / 500 异常。

POST 过账

安全：Bearer 鉴权 + Idempotency-Key 必填；唯一记账入口，事务写（状态 + ledger + onhand + audit）；重复 409 返原结果不重复记账；LY 实发＞可用 403 OVER_ISSUE；SQ/JS/PD 拒绝动账；unit≠base_unit 400。

请求

项说明
Method + PathPOST /api/v1/web/docs/{doc_no}/post
HeadersAuthorization: Bearer TOKEN、Idempotency-Key
Path / Bodydoc_no 单号；Body 可空（LY 校验可用，JS/PD 强制不动账）

请求示例

curl -X POST "http://10.8.0.12:8080/api/v1/web/docs/RK100001/post" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Idempotency-Key: RK100001:1:RK"

响应示例

{
  "code": 200, "msg": "成功",
  "data": {"doc_no":"RK100001","biz_status":"POSTED",
           "ledger_ids":[10000023],"onhand":"updated"},
  "total": 1
}

错误码

400 unit≠base_unit / 401 未鉴权 / 403 OVER_ISSUE（超发）/ SCOPE_DENIED / FLOW_STATE_DENIED（未审批）/ 404 DOC_NOT_FOUND / 409 IDEMPOTENT_REPLAY（返原结果）/ 429 限流 / 500 异常（事务全回滚）。

POST 审批

安全：Bearer 鉴权；按 flow_def 步骤 S1..S6 走，当前审批人匹配才可操作，否则 403；冲红默认高一档权限；审批写 flow_instance.hist + audit_log。

请求

项说明
Method + PathPOST /api/v1/web/docs/{doc_no}/approve
HeadersAuthorization: Bearer TOKEN、Content-Type: application/json
Bodyaction（通过 / 退回）；opinion 意见（退回必填）

请求示例

curl -X POST "http://10.8.0.12:8080/api/v1/web/docs/RK100001/approve" \
  -H "Authorization: Bearer YOUR_TOKEN" -H "Content-Type: application/json" \
  -d '{"action":"通过","opinion":"数量核对无误"}'

响应示例

{"code":200,"msg":"成功","data":{"doc_no":"RK100001","cur_step":"S2","flow_status":"审批中"},"total":1}

错误码

400 参数错（退回缺意见）/ 401 未鉴权 / 403 FLOW_STATE_DENIED（非当前审批人）/ 404 DOC_NOT_FOUND / 429 限流 / 500 异常。
