# 数据字典 V2.1（wms 单库 · MySQL 5.6 · 表-字段-中文解释）

> 版本：V2.1 / 2026-09-20 / 同步 `backend/sql/wms.sql` 61表 / 库名 `wms` / `InnoDB` / `utf8mb4` / 目标 `MySQL 5.6`。
> 规范：主键业务表全 VARCHAR；数量必带 `qty+unit`；金额 `DECIMAL(18,2)`、数量 `DECIMAL(18,3)`；JSON 存 TEXT；5.6 无 CHECK（应用层强制）；逻辑外键（无物理 FK，关联字段全建索引）。
> 术语：`DB=调仓单`（无调拨）；`biz` 只存前缀；`mat_master` 统收编码（含 `CP-`）；单据前缀全集 `SQ/DJ/JS/RK/LY/TL/TK/DB/PD/TZ/CP/JJ/TC`，MVP 先用 `DJ/RK/LY/TL/PD`。
> 编号：`sys_config` 容量声明；`sys_sequence` 中央发号；`sys_biz_state.sid` 语义状态码；`sys_bill_method` 方法字典（`01/02/99`）；树表 `autocode+lowest+parent_code`；快照 `o_/n_`；排序 `gidx/idx/sort/line_no` 与业务键分离；状态 `enabled/biz_status/flow_status/status` 四位分离。
