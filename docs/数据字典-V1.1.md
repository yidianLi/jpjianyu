# 数据字典 V1.1（wms 单库 · MySQL 5.6 · 表-字段-中文解释）

> 版本：V1.1 / 2026-09-20 / 状态：最终版（同步 `backend/sql/wms.sql` 57表）
> 规范：主键业务表全 VARCHAR；数量必带 `qty+unit`；JSON 存 TEXT；5.6 无 CHECK（应用层强制）。
> 术语：`DB=调仓单`（无调拨）；`biz` 只存前缀；`mat_master` 统收编码（含 `CP-`）。
