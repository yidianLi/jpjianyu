# 数据字典 V1.0（wms 单库 · MySQL 5.6 · 表-字段-中文解释）

> 版本：V1.0 / 2026-09-20 / 状态：最终版
> 对应：`backend/sql/wms.sql`（33 表 8 组）+ `docs/SQL表清单-V1.0.md`
> 规范：主键业务表全 VARCHAR；数量必带 `qty+unit`；JSON 存 TEXT；5.6 无 CHECK（应用层强制）。
