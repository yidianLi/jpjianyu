0. 通用规范（腾讯规范落地）

0.1 六原则映射

原则本系统落地
简洁统一动词只用 GET/POST/PUT/PATCH/DELETE；路径全小写下划线名词；返回统一 {code,msg,data,total}；分页统一 page/page_size
语义清晰资源名词=表域：masters/materials、masters/products、masters/boms、stock/ledger、docs、pd_tasks、transfer_ships；单据前缀即 biz
安全可控Bearer 鉴权＋X-Device-Id＋X-Timestamp 防重放；AI 账号禁写；脱敏 phone/sn；PDA 白名单设备
兼容迭代版本号进 URL：/api/v1/web|app|ai；新增只加路由不改旧字段；sys_biz_state/sys_bill_method 加业务只加行不加列
容错性强单行异常不阻断批量，errors[] 逐行回；幂等键冲突直接返原结果；缺码缺批不拦单只标红
性能最优查快照 stock_onhand，仲裁查 stock_ledger；列表强制分页＋LIMIT≤200；TEXT 大字段走附件/引用不进列表

0.2 请求方式 / 路径 / 版本

方式用途示例
GET查询，无请求体可缓存GET /api/v1/web/stock/onhand
POST新增、复杂查询、批量、过账、确认POST /api/v1/web/docs、POST /api/v1/web/docs/{doc_no}/post
PUT全量更新PUT /api/v1/web/masters/materials/{code}
PATCH局部更新（启用/状态/数量）PATCH /api/v1/web/masters/materials/{code}/enabled
DELETE逻辑删除优先（enabled=0/status=停用），物理删除仅关联表DELETE /api/v1/web/system/user_roles
路径：全小写，多词下划线，名词为核心，禁止驼峰大写。版本：/api/v1/…，三命名空间：web（PC）、app（PDA）、ai（问答/OCR薄网关）。V2.2 双主线：物料 masters/materials 与成品 masters/products 平级，BOM 是配方桥，仓储只管地点。

0.3 公共参数（头＋分页）

位置字段必填说明
HeaderAuthorization: Bearer <token>是登录 token；AI 只读账号同样携带，后端按角色禁写
HeaderX-Device-Idapp 必填如 PDA-03；绑定 equipment 白名单
HeaderX-Timestamp是毫秒时间戳，±5分钟外拒绝，防重放
HeaderX-Signapp 写接口必填HMAC(token+timestamp+body)，防篡改
HeaderIdempotency-Key过账/提交必填即 idem_key=doc_no:line_no:biz 口径，重复直接返原结果
Querypage / page_size列表必填默认 1/20，最大 200；禁止自定义分页字段

0.4 统一返回与错误码

{
  "code": 200,
  "msg": "成功",
  "data": {},
  "total": 0
}
code含义业务码
200成功—
400参数错误CHECKLIST_EMPTY / DIFF_REASON_REQUIRED / OVER_ISSUE / INVALID_QTY / BOM_VERSION_REQUIRED
401未鉴权TOKEN_INVALID / TOKEN_EXPIRED
403无权限/被护栏拦SCOPE_DENIED / DUP_SCAN / AI_WRITE_DENIED / FLOW_STATE_DENIED
404不存在DOC_NOT_FOUND / MATERIAL_NOT_FOUND / PRODUCT_NOT_FOUND
409幂等冲突（返回原结果）IDEMPOTENT_REPLAY
429限流RATE_LIMITED
500服务异常—
成功有数据、失败有说明、空值有兜底：data 无数据返 {}/[] 禁返 null；列表必返 total；金额 DECIMAL(18,2)、数量 DECIMAL(18,3)；单据 unit 必须等于物料 base_unit 或成品 base_unit，防米+件混加。
